Web Hosting y Dominios

¿Cómo conseguimos que un sitio web esté disponible en Internet?

¿Qué es Web Hosting?

El Web Hosting es un servicio que proporciona espacio y recursos en servidores conectados a Internet para almacenar los archivos de un sitio web.

Cuando una persona visita una página, el navegador solicita los archivos al servidor y posteriormente los muestra.

Tipos de Hosting

🏠

Compartido

Varios sitios web utilizan recursos de un mismo servidor.

🖥️

VPS

Un servidor físico se divide en servidores virtuales independientes.

☁️

Nube

Utiliza recursos distribuidos entre diferentes servidores.

¿Qué es un dominio?

Un dominio es un nombre que permite identificar un sitio web de una forma sencilla.

¿Qué es un TLD?

TLD significa Top-Level Domain. Es la parte final de un dominio.

.com

Uso comercial y general.

.org

Comúnmente utilizado por organizaciones.

.net

Originalmente relacionado con redes.

Propagación DNS

DNS permite relacionar un nombre de dominio con la información necesaria para encontrar el servidor correspondiente. Cuando se modifican registros DNS, los cambios pueden tardar en reflejarse debido al almacenamiento temporal en diferentes sistemas.
