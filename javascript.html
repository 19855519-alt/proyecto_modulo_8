JavaScript

El lenguaje que permite agregar comportamiento e interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento a las páginas web. Permite responder a las acciones realizadas por los usuarios.

Por ejemplo, JavaScript puede utilizarse para mostrar mensajes, cambiar contenido, validar formularios, crear animaciones y responder cuando una persona presiona un botón.

Conceptos básicos

📦

Variables

Guardan información que puede utilizar el programa. 

let nombre = "William";
⚙️

Funciones

Son bloques de código que realizan una tarea. 

function saludar() {
    alert("Hola");
}
🖱️

Eventos

Permiten responder a acciones del usuario. 

button.addEventListener(
    "click",
    saludar
);

Ejemplo explicado

function saludarUsuario() {

    let nombre = "estudiante";

    document.getElementById("mensajeJS")
        .textContent = "¡Hola " + nombre + "!";

}

Primero se crea una función llamada saludarUsuario(). Después se crea una variable llamada nombre. Finalmente, JavaScript busca el elemento HTML llamado mensajeJS y cambia su contenido.
