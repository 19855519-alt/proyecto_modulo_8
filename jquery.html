jQuery

Una biblioteca de JavaScript creada para simplificar diferentes tareas de desarrollo web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que proporciona funciones para facilitar tareas como seleccionar elementos, modificar páginas web, manejar eventos y crear efectos.

Su popularidad aumentó porque simplificaba muchas tareas que anteriormente requerían escribir más código JavaScript.

Sintaxis básica

$("#titulo").hide();

El símbolo $ es una parte característica de la sintaxis de jQuery. En este ejemplo se selecciona el elemento que tiene el identificador "titulo" y se oculta.

JavaScript vs jQuery

Acción JavaScript jQuery
Seleccionar elemento document.querySelector() $()
Ocultar element.style.display = "none" $(element).hide()
Mostrar element.style.display = "block" $(element).show()
Animación Requiere más código fadeIn(), fadeOut()

Ventajas y desventajas

✓ Ventajas

  • Sintaxis sencilla.
  • Facilita la manipulación del HTML.
  • Incluye efectos y animaciones.
  • Fue muy útil para compatibilidad entre navegadores.

✗ Desventajas

  • Agrega una dependencia al proyecto.
  • JavaScript moderno ya simplifica muchas tareas.
  • No siempre es necesario utilizarlo.
