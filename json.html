JSON

Un formato utilizado para representar e intercambiar datos.

¿Qué significa JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar información de manera organizada.

Es muy utilizado para intercambiar información entre aplicaciones, páginas web, servidores y APIs.

¿Cómo se estructura?

🔑

Clave - valor

{
  "nombre": "William"
}
📋

Arreglos

{
  "lenguajes": [
    "HTML",
    "CSS",
    "JS"
  ]
}
📦

Objetos

{
  "usuario": {
    "nombre": "William",
    "edad": 16
  }
}

Objeto JavaScript vs cadena JSON

Objeto JavaScript

const usuario = {
    nombre: "William",
    edad: 16,
    activo: true
};

JSON

{
    "nombre": "William",
    "edad": 16,
    "activo": true
}

JSON en aplicaciones web

Una página web puede solicitar información a un servidor. El servidor puede responder utilizando JSON.
